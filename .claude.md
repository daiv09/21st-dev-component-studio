# Component Studio Pipeline

Automated pipeline for publishing React components from the `TODO/` folder to 21st.dev using Playwright, Next.js, and the `21st` CLI.

## Quick Setup

```bash
npm i -D @playwright/test concurrently
npx playwright install chromium
npm i -g @21st-dev/cli  # if not already installed
21st login
```

## Pipeline Files

- `.clauderc.md` — Claude Code instructions (run `node scripts/generate-assets.js TODO/<Component>.tsx`)
- `scripts/generate-assets.js` — Playwright script: injects component into `app/page.tsx`, tests mobile/tablet/desktop, captures PNG screenshot, records 6s interaction MP4, converts WebM → MP4 via `ffmpeg`
- `TODO/` — Source folder for unpublished components (only process files already here; do not move other repo files)
- `public/assets/images/` — Generated PNG screenshots
- `public/assets/videos/` — Generated MP4 videos (real MP4, converted from Playwright WebM)

## Key Fix

Playwright records `.webm`; `scripts/generate-assets.js` now auto-converts to `.mp4` with `ffmpeg` so the `21st` CLI accepts the video (`video: skipped` avoided).

## Usage (Manual)

```bash
npm run dev  # start Next.js server (port 3000)
node scripts/generate-assets.js TODO/AIChatInput.tsx
21st publish TODO/AIChatInput.tsx --description "..." --media-dir public/assets --no-open
```
