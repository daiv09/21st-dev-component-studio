# 21st.dev Component Publishing Skill (TODO/ Folder)

When asked to "Run the 21st pipeline" or "Publish components from TODO", execute this workflow strictly for EVERY `.tsx` file inside the `TODO/` directory.

## Workflow Execution Steps

For each file (e.g., `TODO/AIChatInput.tsx`):

1. **Verify Prerequisites:**
   - Ensure `@playwright/test` is installed.
   - Confirm `21st` CLI is installed and authenticated (`21st login` if needed).

2. **Generate Assets (Video & Image):**
   - Ensure the Next.js development server is running (`npm run dev`).
   - Execute the asset generation script:
     `node scripts/generate-assets.js TODO/AIChatInput.tsx`
   - Wait for the script to finish. It handles injecting into `app/page.tsx`, testing responsive viewports, light/dark themes, and generating MP4 + PNG.

3. **Publish to 21st.dev:**
   - Run:
     `21st publish TODO/AIChatInput.tsx --to default --description "Interactive AI chat input component with animated diagnostics"`
   - Adjust `--description` based on the component's function.

4. **Review & Iterate:**
   - Open the CLI Review URL printed in the terminal.
   - If styling is blank or animations fail, fix source in `TODO/` and re-run steps 2 and 3.

5. **Cleanup:**
   - Once published, optionally move the file out of `TODO/` to `published/` or leave it.
