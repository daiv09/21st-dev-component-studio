# Gear Train Differential

Spur gear train feeding a true differential — carrier and spider obey classical axle equations.

**Tags:** `gears` `differential` `kinematics` `canvas` `mechanical`

## Math

```
ω_carrier = (ω_A + ω_B) / 2
ω_spider  = (ω_A − ω_B) / 2
```

Idler ratio −N_A/N_I. Equal axle speeds lock the spider pinion; unequal speeds produce relative rotation.
