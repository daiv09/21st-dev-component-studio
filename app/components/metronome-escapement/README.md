# Metronome Escapement

Mechanical metronome with verge escapement — pallets kick the escape wheel at each extreme.

**Tags:** `metronome` `escapement` `pendulum` `canvas` `mechanical`

## Math

Phase ∈ [−1,1] driven at ω = π·BPM/60. At extremes, velocity reverses and escape wheel advances π/6 (tooth). Weight position maps to tempo visually.
