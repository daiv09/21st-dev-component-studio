# Phenakistoscope Disk

Stroboscopic slit animation — spinning disk frames revealed through a fixed shutter.

**Tags:** `phenakistoscope` `strobe` `animation` `canvas` `optics`

## Math

N frames at angles 2πi/N. Disk rotates at ω. Fixed slit with duty cycle d samples one frame per sync period when ω ≈ 2π·fps/N (persistence of vision).
