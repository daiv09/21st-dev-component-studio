# Theremin Field

Dual-antenna proximity instrument — vertical rod pitch, loop volume, field ∝ 1/(d+ε).

**Tags:** `theremin` `proximity` `field` `svg` `interactive`

## Math

```
pitch  = clamp(1 − |x − x_rod| / R)
volume = clamp(1 − |y − y_loop| / R)
```

Isorings visualize capacitive field strength around each antenna.
