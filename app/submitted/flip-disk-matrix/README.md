# Flip-Disk Matrix

Electromagnetic flip-disk bitmap — each disk snaps between two hard faces like classic public departure boards.

**Tags:** `bitmap` `flip-disk` `matrix` `typography` `mechanical`

## Math / Tech

Target bitmask T(x,y,t) from clock glyphs, traveling wave `sin(xω + t) + cos(yν + t) > τ`, or Bernoulli noise. Disks transition with `steps(2)` timing to emulate solenoid latch, not soft fades.
