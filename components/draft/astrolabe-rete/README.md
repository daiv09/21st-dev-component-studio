# Astrolabe Rete

Stereographic tympan (almucantars + azimuths) under a rotatable rete of star pointers.

**Tags:** `astrolabe` `stereographic` `astronomy` `svg` `rete`

## Math

Stereographic ρ = R·cos(a)/(1+sin(a)). Almucantars offset by co-latitude. Rete stars placed by (RA, Dec) then rotated by sidereal angle.
