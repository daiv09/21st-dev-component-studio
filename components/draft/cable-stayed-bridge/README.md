# Cable-Stayed Bridge

Tower, stays, and main cables with parabolic-catenary sag under live deck loads.

**Tags:** `bridge` `catenary` `statics` `svg` `structure`

## Math

Cable approximation `y = (1−t)y₀ + t y₁ + 4s t(1−t)` (parabolic catenary under uniform load). Deck deflection ∝ load·sin(πt). Stay thickness encodes relative tension.
