# Calder Mobile

Torque-balanced kinetic sculpture — hanging beams satisfy m₁r₁ = m₂r₂ under wind gusts.

**Tags:** `physics` `constraint` `kinetic` `canvas` `calder`

## Math

Rods are distance constraints solved by iterative position correction. Lateral wind `W·sin(t)` perturbs masses; damping 0.992. Balance: heavier masses sit closer to the fulcrum so net torque ≈ 0 at rest.
