# Foucault Pendulum

Precessing pendulum whose swing plane rotates with Ω = −ω_earth·sin(φ), etching a rose on the floor.

**Tags:** `physics` `foucault` `precession` `canvas` `earth`

## Math

```
Ω = −ω · sin(φ)
x = A · cos(Ωt) · sin(ωt)
```

Latitude φ drives precession rate. Trail records bob projection on the etched floor ellipse.
