# Kinetic Collection

## Tech

- **No external libraries** (no Three.js, GSAP, Framer Motion, Lottie, etc.)
- Pure Canvas 2D + requestAnimationFrame
- DPR-aware for crisp rendering on retina displays
- Cursor/mouse reactive where it makes sense
- Touch support on key components
