# Louver Aperture

Synchronized slat aperture — one linkage tilts all louvers; projected height = h·cos θ.

**Tags:** `louver` `aperture` `linkage` `svg` `optics`

## Math

θ = open · θ_max. Each slat rendered as parallelogram with vertical projected thickness h·cos θ and foreshortening skew ∝ sin θ. Shared side bar enforces sync.
