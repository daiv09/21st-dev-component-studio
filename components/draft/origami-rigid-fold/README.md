# Origami Rigid Fold

Rigid-panel origami with dihedral crease angles — waterbomb, Miura-ori, preliminary base.

**Tags:** `origami` `rigid-fold` `dihedral` `svg` `geometry`

## Math

Panels rotate via Rodrigues’ formula about crease axes. Dihedral θ(t) = fold · θ_target. Depth-sorted projected polygons (no R3F).
