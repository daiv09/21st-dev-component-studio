# Pantograph Tracer

Parallelogram linkage that scales stylus motion onto an output plane — classic drafting pantograph.

**Tags:** `linkage` `kinematics` `svg` `drawing` `interactive`

## Math

Fixed pivot F, stylus S, scale k:

```
O = F + k · (S − F)
```

Arms form a parallelogram so the output pen traces a homothetic copy of the input path.
