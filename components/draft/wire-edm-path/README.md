# Wire EDM Path

Spark-erosion wire toolpath cutting a kerf through the workpiece with live spark particles.

**Tags:** `edm` `toolpath` `cnc` `svg` `manufacturing`

## Math / Tech

Electrode advances along polyline at feed rate. Kerf = wire diameter + spark gap, drawn as stroke width. Sparks spawn at head with lifetime decay (flat dots, no glow gradients).
